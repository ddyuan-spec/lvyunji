二、项目背景与目标

2.1 业务背景

绿韵家App正在将原有小程序「数智」能力升级为以AI健康助手为核心的健康档案中心。当前原型已画出首页入口、健康档案详情、记录弹窗等界面，但缺少具体的交互规则与边界条件，尤其是：

  1. 当天无记录的空状态未明确页面如何展示、用户如何被引导去记录；
  2. 日/周/月/年切换的统计口径与下方展示规则（列表 vs 趋势图）未定义；
  3. 记录操作（删除、编辑、来源）未定义；
  4. 基础信息的触发条件与必填规则未明确。

2.2 项目目标

目标维度具体指标/描述优先级
记录闭环用户在健康档案任何时间维度下都能清晰看到当天是否有记录，并一键补录P0
数据可读日/周/月/年切换后，顶部关键指标与下方趋势/列表展示口径一致、无歧义P0
体验简洁记录操作路径短，删除后可直接重新录入，不强制编辑旧记录P1

2.3 衡量指标（KPI）

指标说明目标

记录完成率点击「去记录」后成功保存记录的比例≥ 95%
基础信息完善率查看BMI/体脂率的用户中，已完善性别/生日/身高的占比≥ 60%（占位基线，待产品负责人确认）

三、业务流程与架构

3.1 页面信息架构

「数智-健康档案」功能链路由以下页面/弹窗组成：

  1. 数智首页 — AI助手入口聚合页，点击「AI帮你看」等区域进入对话页；
  2. 数智对话页 — 聊天界面，底部快捷入口可跳转「健康档案」「健康盒子」；
  3. 健康档案详情页 — 核心页面，展示日/周/月/年维度下的体重、BMI、体脂率及记录列表/趋势图；
  4. 记录身体数据弹窗 — 手动录入体重、体脂率、腰围、身高、日期、时间；
  5. 完善基础信息弹窗/页面 — 补充性别、生日、身高，用于计算BMI/体脂率。

3.2 主业务流程

  1. 用户通过底部Tab进入「数智」首页；
  2. 用户点击入口进入「健康档案」详情页；
  3. 系统加载当前选中日期/周期的健康数据：
    • 若当天有记录，顶部显示最新体重/BMI/体脂率，下方展示记录列表或趋势图；
    • 若当天无记录，顶部显示「--」或最近一次数据，中部展示空状态插画+「去记录」按钮；
  4. 用户点击「去记录」，弹出「记录身体数据」弹窗；
  5. 用户填写数据并确认，系统校验后保存；
  6. 保存成功后弹窗关闭，详情页刷新展示最新记录；
  7. 用户查看BMI/体脂率时，若缺少性别/生日/身高，触发「完善基础信息」弹窗。
范围外声明：本需求不涉及商家端后台、设备同步连接、健康盒子（百宝箱）物品管理、AI拍照识别、AI帮你买/省/选/看的对话逻辑。

界面与展示规则：

字段/区域需求说明备注
页面标题顶部导航栏居中显示「健康档案」，左侧返回按钮，右侧用户头像沿用现有
时间维度Tab日 / 周 / 月 / 年 四个Tab，默认选中「日」切换时保持当前日期所在周期
日期导航左右箭头切换上/下一周期，中间显示当前周期范围，「回今天」按钮返回今日周期日视图显示「X月X日」；周视图显示「X月X日-X月X日」；月视图显示「X月」；年视图显示「X年」

记录列表（日视图）展示当天唯一一条身体数据记录（按记录日期唯一）；点击该记录进入记录弹窗（编辑/覆盖模式）展示数值、时间、数据来源；一天仅保留一条
身体趋势（周/月/年视图）展示体重/BMI/体脂率随时间变化曲线，可切换指标与单位（kg/斤）取该周期内各日唯一记录点（一天一条）
空状态当天/当周/当月/当年无记录时，中部展示空插画与文案，底部保留「去记录」按钮详见4.3.3
去记录按钮页面底部固定悬浮/置底大按钮，文案「去记录」点击唤起记录弹窗
数据精度统一规则（全局）：本需求所有身体指标（体重、身高、体脂率、腰围）的输入、展示与存储精度统一为小数点后1位（如 67.0、23.2、20.0）；BMI 由体重与身高计算得出，同样保留1位小数。计算与四舍五入：采用四舍五入，展示层与存储层保持一致。

业务逻辑与边界条件：

  1. 日视图加载逻辑：
    • 进入页面默认加载「今日」数据；
    • 若今日有记录：顶部指标取今日唯一记录；下方展示该条记录（点击可编辑/覆盖）；
    • 若今日无记录：顶部指标显示「--」或最近一次记录（带「今日未记录」提示）；列表区展示空状态+「去记录」按钮。
  2. 周/月/年视图加载逻辑：
    • 顶部大数字取该周期结束日那条记录（一天一条，即结束日的唯一记录）；
    • 下方展示趋势图，X轴为该周期内日期，Y轴为数值；
    • 若该周期内无记录：展示空状态+「去记录」按钮，趋势图为空。
  3. 单位切换：
    • 体重支持 kg / 斤 切换，1kg = 2斤；
    • 切换仅影响展示，后端统一存储kg；
    • 默认展示kg。
  4. 删除交互（物理删除，一天一条）：
    • 当天仅存在一条记录；用户在记录项上左滑，出现「删除」按钮；
    • 点击「删除」后二次确认弹窗「确定删除这条记录吗？删除后不可恢复」；
    • 确认删除后后端物理删除该日记录，列表与顶部指标清空，页面切换为空状态+「去记录」按钮；
    • 删除后该日无任何记录，用户再次点击「去记录」为新建（不会恢复旧数据）。
  5. BMI/体脂率计算触发：
    • 当用户查看BMI或体脂率时，若缺少性别/生日/身高任一字段，弹出「完善基础信息」弹窗；
    • 完善后才显示BMI等级标签与体脂率分析。

4.4.1 页面原型与交互示意

图5：记录身体数据弹窗，可录入日期、时间、体重、体脂率、腰围、身高

4.4.2 详细逻辑规则

需求影响范围：本期新增弹窗，用于手动录入身体数据。录入后实时影响健康档案详情页展示与BMI计算。

涉及终端明细：App端（iOS/Android）。

界面与展示规则：

字段/区域需求说明备注
弹窗标题「记录身体数据」顶部关闭按钮 X
记录日期默认选中当前日期，点击唤起日期选择器可补录历史日期，不可选择未来日期
记录时间默认当前时间，点击唤起时间选择器精确到分钟
体重（kg）必填，数字输入框，默认带入最近一次体重值输入范围 2.0~300.0，最多1位小数（常见人类占位值，待产品确认）
体脂率（%）选填，数字输入框，默认带入最近一次体脂率值输入范围 2.0~75.0，最多1位小数（常见人类占位值，待产品确认）
腰围（cm）选填，数字输入框，默认带入最近一次腰围值输入范围 30.0~200.0，最多1位小数（常见人类占位值，待产品确认）
身高（cm）选填，数字输入框，默认带入用户基础信息身高保存时同步更新《用户基础信息表》.height（覆盖原值，影响BMI/体脂率计算）；输入范围 30.0~250.0，最多1位小数（占位）
确认按钮底部固定大按钮，默认置灰，必填项填写完整且校验通过后高亮可点击点击后保存并关闭弹窗

业务逻辑与边界条件：

  1. 默认值规则：
    • 记录日期默认今日；
    • 记录时间默认当前系统时间；
    • 体重默认取用户最近一次有效记录值，无记录时显示提示文案「请输入体重」；
    • 体脂率、腰围默认取最近一次有效记录值，无记录时显示提示文案「请输入」；
    • 身高默认取用户基础信息中的身高，未填写时显示提示文案「请输入身高」。
    • 若所选日期当日已存在记录，弹窗预填该记录全部字段值（编辑/覆盖模式），保存即覆盖该日记录；若当日无记录则为新建模式。
  2. 校验规则：
    • 体重必填，为空时点击确认提示「请输入体重」；
    • 体重、体脂率、腰围、身高均为数字，非法字符输入时拦截并提示「只能输入数字」；
    • 记录日期不能选择未来日期，选择未来日期时提示「不能选择未来日期」；
    • 数值范围：体重 2.0~300.0kg、身高 30.0~250.0cm、体脂率 2.0~75.0%、腰围 30.0~200.0cm，超出范围提示「数值超出正常范围，请核对」；所有数值最多1位小数，超出小数位提示「最多保留1位小数」。（区间均为常见人类占位值，待产品负责人确认）
  3. 保存逻辑：
    • 校验通过后，将记录写入《用户身体数据记录表》；
    • 按记录日期唯一，一天只保留一条记录：保存时若当日已存在记录则覆盖更新（update），否则新增（insert）；记录弹窗中修改的身高同步写入《用户基础信息表》.height；
    • 保存成功后Toast提示「记录成功」，弹窗关闭，详情页刷新；
    • 保存失败时保持弹窗，提示具体错误信息。
  4. 防重与网络异常：
    • 提交时按钮进入loading态，防止重复提交；
    • 弱网/断网时提示「网络异常，请稍后重试」，用户可再次点击确认；
    • 后端返回重复提交时，前端提示「请勿重复提交」。

需求影响范围：本期明确基础信息的触发条件与保存规则。基础信息用于BMI/体脂率计算，不强制首次进入填写。

涉及终端明细：App端（iOS/Android）。

界面与展示规则：

字段/区域需求说明备注

出生日期日期选择器，必填默认未选择，格式 YYYY-MM-DD
身高数字输入框，单位cm，必填范围 30.0~250.0，最多1位小数（常见人类占位值，待产品确认）
确认保存按钮底部固定大按钮，必填项完整后高亮可点击保存后关闭弹窗

业务逻辑与边界条件：

  1. 触发条件：
    • 用户查看BMI等级标签或体脂率分析时，若缺少性别/生日/身高任一字段，自动弹出完善信息弹窗；
    • 用户点击健康档案详情页「编辑基础信息」按钮，进入基础信息编辑页；
    • 不强制用户首次进入健康档案时填写。
  2. 校验规则：
    • 性别必选，未选提示「请选择性别」；
    • 出生日期必选，未选提示「请选择出生日期」；
    • 身高必填，为空提示「请输入身高」；非法字符拦截；
    • 身高范围 30.0~250.0cm，超出提示「数值超出正常范围」；最多1位小数。
  3. 保存逻辑：
    • 校验通过后写入《用户基础信息表》；
    • 保存成功后，健康档案详情页重新计算并展示BMI/体脂率；
    • 弹窗场景保存后自动关闭；页面场景保存后返回详情页。
