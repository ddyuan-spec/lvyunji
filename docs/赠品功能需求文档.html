一需求概述
1.1 背景

为提升商品营销能力，绿韵家后台管理系统需在商品管理模块中增加赠品管理功能。商家可为商品的不同规格配置赠品赠送规则，当用户订单满足指定条件时，系统自动将赠品加入订单。

1.2 目标
  • ✅ 支持按商品规格配置赠品赠送条件（按购买数量 / 按实付金额）
  • ✅ 赠品随主商品一同进入订单，标记为"赠品"，售价显示为 ¥0
  • ✅ 赠品不参与售后流程
  • ✅ 同一规格支持多条件叠加，满足多个条件时赠品叠加赠送
1.3 适用范围
  • 后台管理系统：商品列表页、新增/编辑商品页
  • 订单系统：订单详情页展示赠品信息

2.2 新增/编辑商品页 · 赠品规则配置
2.2.1 页面位置

商品管理 > 新增商品 / 编辑商品

2.2.2 功能描述

在商品基础信息填写区域下方，增加"赠品规则"配置区块：

🎁 赠品规则（按规格配置）
多条件叠加规则：同一规格下可配置多个赠送条件（按数量 / 按金额），各条件独立判断、可同时满足。若订单同时满足多个条件，则赠品叠加赠送。
2.2.3 赠品条件数据结构
// 规格 -> [条件] 映射
// 每个条件: { id, type, threshold, giftQty, dateStart, dateEnd, gifts:[] }
{
    '120粒/瓶': [
        {
            id: 'c1',
            type: 'amount',        // qty=按数量, amount=按金额
            threshold: 500,              // 触发阈值
            giftQty: 1,                // 赠送数量
            dateStart: '2026-06-01',   // 有效期开始
            dateEnd: '2026-12-31',     // 有效期结束
            gifts: [                    // 赠品列表
                { productId: 4, name: '草本护发精油（小样）',
                  code: 'SP20260604004', spec: '10ml小样', qty: 1 }
            ]
        }
    ]
}

弹窗标题：新增赠品条件

1

展示当前商品所有规格选项
多选，以下规格购买时触发本规则
2
设置条件参数
📦 按购买数量
💰 按实付金额
📅 设置有效期
3
选择赠品商品
从赠品商品池选择
为每个赠品配置规格+数量
第1步：选择适用规格
  • 展示当前商品的所有规格选项（多选）
  • 文案提示："选择适用的商品规格（多选，以下规格购买时触发本赠品规则）"
第2步：设置条件参数
📦 按购买数量赠送 — 买 X 件赠送 Y 件赠品
触发数量：输入框（件及以上）
实时预览：✅ 购买满 10 件，赠送对应数量赠品
💰 按实付金额赠送 — 实付满 X 元赠送 Y 件赠品
实付金额：输入框（元及以上）
实时预览：✅ 订单实付金额满 ¥100.00，赠送对应数量赠品
📅 有效期配置
开始日期：日期选择器
结束日期：日期选择器
· 有效期内下单且满足数量/金额条件才会赠送
· 过期条件自动失效
第3步：选择赠品商品
  • 赠品商品列表：从赠品商品池中选择
  • 每个赠品商品展示：图片、名称、编号、规格选项、价格
  • 已选赠品计数显示
  • 已选赠品配置区：为每个已选赠品单独配置规格、赠送数量
弹窗底部按钮： 取消  |  确认添加条件
2.3 编辑赠品弹窗
2.3.1 触发方式
  • 商品列表页点击【编辑赠品】按钮
  • 新增/编辑商品页点击已有条件的【编辑】按钮
2.3.2 弹窗结构
弹窗标题：编辑商品赠品 · {商品名称}
📊 顶部统计信息
共 N 个规格配置了赠品
M 条赠品条件，K 个赠品配置
· 多条件满足时叠加赠送 · 赠品不参与售后
📦 内容区域（按规格分组展示）
每个规格一个分组卡片：
· 规格名称（如：240粒/瓶）
· 条件数量提示：共 {N} 条条件（满足任一条件即触发对应赠品，多满足多赠）
· 每个条件展示为条件卡片
📋 条件卡片内容
· 条件类型图标（📦 按数量 / 💰 按金额）
· 条件类型标签
· 规则文案：购买满 N 件，赠送 M 件赠品 / 实付满 ¥N，赠送 M 件赠品
· 赠品列表（迷你卡片：图片+名称+数量）
· 有效期：开始日期 ~ 结束日期（即将过期标黄提醒）
· 操作按钮：编辑、删除
📭 空状态
此规格暂未配置赠品条件（虚线框提示）
➕ 底部操作
· 新增条件（为该规格新增赠品条件）
· 为其他规格配置赠品
弹窗底部按钮： 取消  |  保存

三业务规则
3.1 赠品规则
规则项说明
赠品售价赠品在订单中售价固定为 ¥0.00
赠品库存赠品需有独立库存管理，赠送时扣减库存
多条件叠加同一规格下多个条件独立判断，同时满足时赠品叠加赠送
有效期控制赠品条件需在有效期内才生效，过期自动失效
规格关联不同规格可配置不同的赠品规则，互不影响
3.2 售后规则
规则项说明
赠品售后赠品不参与售后流程（不支持退货、换货、退款）
主商品售后主商品退货/退款时，赠品随主商品一并处理
售后按钮赠品行不展示"申请售后"按钮，显示"赠品不支持售后"
3.3 订单计算规则
规则项说明
赠品金额赠品小计固定为 ¥0.00，不计入应付金额
订单总额应付金额 = 主商品金额之和（不含赠品）
赠品价值展示订单汇总行标注"含赠品价值 ¥{N}"，仅作展示
四字段定义
4.1 赠品条件字段
字段名类型必填说明
idString是条件唯一标识
typeEnum是条件类型：qty（按数量）/ amount（按金额）
thresholdInteger是触发阈值（件数或金额）
giftQtyInteger是赠送赠品总数量
dateStartDate是有效期开始日期
dateEndDate是有效期结束日期
giftsArray是赠品列表
4.2 赠品商品字段
字段名类型必填说明
productIdInteger是赠品商品ID
nameString是赠品商品名称
codeString是赠品商品编号
specString是赠品规格
qtyInteger是赠送数量
imgString否赠品图片
4.3 订单赠品字段
字段名类型说明
isGiftBoolean是否为赠品（true=赠品）
triggerString触发条件类型（qty/amount）
triggerTextString触发条件描述文案
linkedSpecString关联的主商品规格

  • ⚡ 赠品条件查询响应时间 < 200ms
  • ⚡ 订单赠品计算在下单流程中同步完成，不影响下单体验
7.2 兼容性要求
  • 🌐 支持 Chrome、Firefox、Safari、Edge 等主流浏览器
  • 🖥️ 后台管理系统适配 1920×1080 及以上分辨率
7.3 安全要求
  • 🔐 赠品配置操作需校验管理员权限
  • 📝 赠品条件修改记录操作日志
