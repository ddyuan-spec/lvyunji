# 绿韵家后台管理系统 - 赠品功能需求文档

**文档版本**：V1.0  
**编写日期**：2026-06-04  
**适用系统**：绿韵家后台管理系统（商品管理模块）

---

## 一、需求概述

### 1.1 背景
为提升商品营销能力，绿韵家后台管理系统需在商品管理模块中增加**赠品管理功能**。商家可为商品的不同规格配置赠品赠送规则，当用户订单满足指定条件时，系统自动将赠品加入订单。

### 1.2 目标
- 支持按商品规格配置赠品赠送条件（按购买数量 / 按实付金额）
- 赠品随主商品一同进入订单，标记为"赠品"，售价显示为 ¥0
- 赠品不参与售后流程
- 同一规格支持多条件叠加，满足多个条件时赠品叠加赠送

### 1.3 适用范围
- 后台管理系统：商品列表页、新增/编辑商品页
- 订单系统：订单详情页展示赠品信息

## 二、功能模块

### 2.1 商品列表页 - 编辑赠品入口

#### 2.1.1 页面位置
商品管理 > 商品列表

#### 2.1.2 功能描述
- 商品列表表格每行操作列提供【编辑赠品】文字按钮
- 点击后打开"编辑赠品"弹窗，对应该商品的赠品配置

#### 2.1.3 交互流程
```
商品列表页 → 点击【编辑赠品】→ 打开编辑赠品弹窗 → 配置赠品规则 → 保存
```

---

### 2.2 新增/编辑商品页 - 赠品规则配置

#### 2.2.1 页面位置
商品管理 > 新增商品 / 编辑商品

#### 2.2.2 功能描述
在商品基础信息填写区域下方，增加"赠品规则"配置区块：

**区块标题**：🎁 赠品规则（按规格配置）  
**右侧按钮**：+ 新增赠品条件

**规则说明文案**：
> 💡 **多条件叠加规则**：同一规格下可配置多个赠送条件（按数量 / 按金额），各条件独立判断、可同时满足。若订单同时满足多个条件，则赠品叠加赠送。

#### 2.2.3 赠品条件数据结构

```javascript
// 规格 -> [条件] 映射
// 每个条件: { id, type, threshold, giftQty, dateStart, dateEnd, gifts:[] }
{
    '120粒/瓶': [
        { 
            id: 'c1', 
            type: 'amount',        // 条件类型：qty=按数量, amount=按金额
            threshold: 500,        // 触发阈值
            giftQty: 1,            // 赠送数量
            dateStart: '2026-06-01',  // 有效期开始
            dateEnd: '2026-12-31',    // 有效期结束
            gifts: [               // 赠品列表
                { productId: 4, name: '草本护发精油（小样）', code: 'SP20260604004', spec: '10ml小样', qty: 1 }
            ] 
        }
    ]
}
```

#### 2.2.4 新增赠品条件弹窗（三步流程）

**弹窗标题**：新增赠品条件

**步骤指示器**：
1. 选择适用规格 → 2. 设置条件参数 → 3. 选择赠品(规格+数量)

**第1步：选择适用规格**
- 展示当前商品的所有规格选项（多选）
- 文案提示："选择适用的商品规格（多选，以下规格购买时触发本赠品规则）"

**第2步：设置条件参数**

条件类型切换标签：
- 📦 **按购买数量赠送** —— 买 X 件赠送 Y 件赠品
- 💰 **按实付金额赠送** —— 实付满 X 元赠送 Y 件赠品

**按数量配置项**：
- 触发数量：输入框（件及以上）
- 实时预览：✅ 预览：购买满 {N} 件，赠送对应数量赠品

**按金额配置项**：
- 实付金额：输入框（元及以上）
- 实时预览：✅ 预览：订单实付金额满 ¥{N}.00，赠送对应数量赠品

**有效期配置**：
- 开始日期：日期选择器
- 结束日期：日期选择器
- 提示文案：
  - 有效期内下单且满足数量/金额条件才会赠送
  - 过期条件自动失效

**第3步：选择赠品商品**
- 赠品商品列表（从赠品商品池中选择）
- 每个赠品商品展示：图片、名称、编号、规格选项、价格
- 已选赠品计数显示

**已选赠品配置区**：
- 为每个已选赠品单独配置：规格、赠送数量
- 赠品规格从该赠品的可用规格中选择

**弹窗底部按钮**：
- 取消
- 确认添加条件

### 2.3 编辑赠品弹窗

#### 2.3.1 触发方式
- 商品列表页点击【编辑赠品】按钮
- 新增/编辑商品页点击已有条件的【编辑】按钮

#### 2.3.2 弹窗结构

**弹窗标题**：编辑商品赠品 · {商品名称}

**顶部统计信息**：
- 共 {N} 个规格配置了赠品
- {M} 条赠品条件，{K} 个赠品配置
- 多条件满足时叠加赠送 · 赠品不参与售后

**内容区域（按规格分组展示）**：

每个规格一个分组卡片：
- 规格名称（如：240粒/瓶）
- 条件数量提示：共 {N} 条条件（满足任一条件即触发对应赠品，多满足多赠）
- 每个条件展示为条件卡片

**条件卡片内容**：
- 条件类型图标（📦 按数量 / 💰 按金额）
- 条件类型标签
- 规则文案：
  - 按数量：购买满 **{N}** 件（含以上），赠送 **{M}** 件赠品
  - 按金额：订单实付金额满 **¥{N}**（含以上），赠送 **{M}** 件赠品
- 赠品列表（迷你卡片展示：图片+名称+数量）
- 有效期：{开始日期} ~ {结束日期}（即将过期标黄提醒）
- 操作按钮：编辑、删除

**空状态**：
- 此规格暂未配置赠品条件（虚线框提示）

**底部操作**：
- + 新增条件（为该规格新增赠品条件）
- + 为其他规格配置赠品

**弹窗底部按钮**：
- 取消
- 保存

### 2.4 订单详情页 - 赠品展示

#### 2.4.1 页面位置
订单中心 > 订单详情

#### 2.4.2 赠品信息卡片

订单信息区域下方，展示赠品汇总卡片：

**卡片样式**：左侧黄色边框，浅黄色背景

**卡片内容**：
- 🎁 图标
- 标题：本订单触发 **{N}个** 赠品条件，共赠送 **{M}件** 赠品（叠加赠送）
- 条件明细列表：
  - 条件1（按数量）：购买满{N}件 → 赠「{赠品名}」×{数量}件
  - 条件2（按金额）：实付满{N}元 → 赠「{赠品名}」×{数量}件

#### 2.4.3 商品清单中的赠品展示

商品清单表格增加赠品行，与主商品区分：

**赠品行样式**：
- 行背景色：#fffafa（浅粉色）
- 商品名称后增加【赠品】标签

**赠品行字段**：
- 图片：赠品商品图片
- 商品名称 / 规格：赠品名称 + 【赠品】标签 + 规格信息 + 触发来源标签
- 单价：¥0.00（灰色显示）
- 数量：×{数量}
- 小计：¥0.00（灰色显示）
- 类型/来源：【赠品】蓝色标签
- 操作："赠品不支持售后"（灰色文字，不可点击）

**订单金额汇总**：
- 商品金额：¥{主商品金额}
- 赠品价值（赠送）：¥0.00
- 应付金额：¥{总金额}（含赠品价值 ¥{赠品总价值}）

## 三、业务规则

### 3.1 赠品规则

| 规则项 | 说明 |
|--------|------|
| 赠品售价 | 赠品在订单中售价固定为 ¥0.00 |
| 赠品库存 | 赠品需有独立库存管理，赠送时扣减库存 |
| 多条件叠加 | 同一规格下多个条件独立判断，同时满足时赠品叠加赠送 |
| 有效期控制 | 赠品条件需在有效期内才生效，过期自动失效 |
| 规格关联 | 不同规格可配置不同的赠品规则，互不影响 |

### 3.2 售后规则

| 规则项 | 说明 |
|--------|------|
| 赠品售后 | 赠品**不参与**售后流程（不支持退货、换货、退款） |
| 主商品售后 | 主商品退货/退款时，赠品随主商品一并处理 |
| 售后按钮 | 赠品行不展示"申请售后"按钮，显示"赠品不支持售后" |

### 3.3 订单计算规则

| 规则项 | 说明 |
|--------|------|
| 赠品金额 | 赠品小计固定为 ¥0.00，不计入应付金额 |
| 订单总额 | 应付金额 = 主商品金额之和（不含赠品） |
| 赠品价值展示 | 订单汇总行标注"含赠品价值 ¥{N}"，仅作展示 |

## 四、字段定义

### 4.1 赠品条件字段

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 条件唯一标识 |
| type | Enum | 是 | 条件类型：qty（按数量）/ amount（按金额） |
| threshold | Integer | 是 | 触发阈值（件数或金额） |
| giftQty | Integer | 是 | 赠送赠品总数量 |
| dateStart | Date | 是 | 有效期开始日期 |
| dateEnd | Date | 是 | 有效期结束日期 |
| gifts | Array | 是 | 赠品列表 |

### 4.2 赠品商品字段

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| productId | Integer | 是 | 赠品商品ID |
| name | String | 是 | 赠品商品名称 |
| code | String | 是 | 赠品商品编号 |
| spec | String | 是 | 赠品规格 |
| qty | Integer | 是 | 赠送数量 |
| img | String | 否 | 赠品图片 |

### 4.3 订单赠品字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| isGift | Boolean | 是否为赠品（true=赠品） |
| trigger | String | 触发条件类型（qty/amount） |
| triggerText | String | 触发条件描述文案 |
| linkedSpec | String | 关联的主商品规格 |

## 七、非功能需求

### 7.1 性能要求
- 赠品条件查询响应时间 < 200ms
- 订单赠品计算在下单流程中同步完成，不影响下单体验

### 7.2 兼容性要求
- 支持 Chrome、Firefox、Safari、Edge 等主流浏览器
- 后台管理系统适配 1920×1080 及以上分辨率

### 7.3 安全要求
- 赠品配置操作需校验管理员权限
- 赠品条件修改记录操作日志
