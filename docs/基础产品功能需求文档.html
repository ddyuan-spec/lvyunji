一需求概述
1.1 背景

为支持售后退款时按基础产品数量进行退款（如：10个装玉米退3个单个玉米），绿韵家后台管理系统需在商品管理模块中增加基础产品管理功能。商家可为商品的不同规格绑定对应的基础产品，售后退款时按基础产品数量计算退款金额。

1.2 目标
  • ✅ 支持按商品规格绑定基础产品（如：10个装 → 10个单个玉米）
  • ✅ 售后退款时支持按基础产品数量退款
  • ✅ 退款金额 = 退款数量 × 基础产品单价
  • ✅ 同一规格可绑定多个基础产品
1.3 适用范围
  • 后台管理系统：商品列表页、新增/编辑商品页
  • 订单系统：订单详情页售后退款

2.2 新增/编辑商品页 · 基础产品配置
2.2.1 页面位置

商品管理 > 新增商品 / 编辑商品

2.2.2 功能描述

在商品基础信息填写区域下方，增加"基础产品"配置区块：

🌽 基础产品（按规格绑定）
基础产品规则：为每个商品规格绑定对应的基础产品（如：10个装玉米 → 基础产品为10个单个玉米）。售后退款时，可按基础产品数量进行退款，退款金额 = 退款数量 × 基础产品单价。
2.2.3 基础产品数据结构
// 规格 -> [基础产品绑定] 映射
// 每个绑定: { baseProductId, name, code, spec, qty, price, img }
{
    '120粒/瓶': [
        {
            baseProductId: 101,
            name: '有机玉米（单个）',
            code: 'BASE20260601001',
            spec: '约200g/个',
            qty: 5,              // 该规格包含5个基础产品
            price: 2.5,           // 基础产品单价
            img: '🌽'
        }
    ],
    '240粒/瓶': [
        { baseProductId: 101, name: '有机玉米（单个）', qty: 10, price: 2.5 },
        { baseProductId: 102, name: '土鸡蛋（单个）', qty: 3, price: 1.2 }
    ]
}
2.2.4 编辑基础产品弹窗
弹窗结构
弹窗标题：编辑基础产品 · {商品名称}
顶部统计：N 个规格已配置，M 个基础产品绑定
内容区域：按规格分组展示基础产品绑定列表
规格分组卡片
· 规格名称（如：240粒/瓶）
· 基础产品数量提示：共 N 个基础产品
· 每个基础产品展示为表格行：图片+名称+编号+规格+单价+数量+操作
· 数量可编辑（input number）
· 操作按钮：删除
· 【+ 添加基础产品】按钮
2.2.5 选择基础产品弹窗
弹窗结构
弹窗标题：选择基础产品
搜索框：搜索基础产品名称/编号
列表项：圆形单选框 + 图片 + 名称 + 编号 + 单价 + 规格
选中效果：整行蓝色边框 + 浅蓝背景 + 勾选框变蓝白 ✓
底部按钮：取消 | 确认选择

三业务规则
3.1 基础产品规则
规则项说明
绑定关系每个商品规格可绑定多个基础产品
基础产品数量表示该规格包含的基础产品个数（如10个装玉米 → qty=10）
基础产品单价独立定价，用于计算退款金额
不同规格不同规格可绑定不同的基础产品，互不影响
3.2 售后退款规则
规则项说明
退款方式支持订单商品退款和基础商品退款两种方式
基础商品退款按基础产品数量退款，退款金额 = 退款数量 × 基础单价
退款上限基础商品退款金额合计不能超过订单实际支付金额；系统需累计已退基础商品金额，确保所有基础商品退款金额之和 ≤ 订单实际金额
金额计算系统自动计算：退款数量 × 基础单价 = 本次退款金额
四字段定义
4.1 基础产品绑定字段
字段名类型必填说明
baseProductIdInteger是基础产品ID
nameString是基础产品名称
codeString是基础产品编号
specString是基础产品规格
qtyInteger是绑定数量（该规格包含的基础产品个数）
priceDecimal是基础产品单价
imgString否基础产品图片
4.2 基础产品池字段
字段名类型必填说明
idInteger是基础产品唯一ID
nameString是基础产品名称
codeString是基础产品编号
specString是规格描述
priceDecimal是单价
imgString否图片

六界面原型参考
6.1 商品列表页
· 表格列：图片、商品名称、商品编号、价格、商品类型、状态、操作
· 操作列按钮：编辑 | 编辑赠品 | 编辑基础产品 | 查看
6.2 编辑基础产品弹窗
· 按规格分组展示基础产品绑定
· 每个规格卡片：规格名称 + 基础产品数量 + 添加按钮
· 基础产品表格：图片、名称、编号、规格、单价、数量(input)、删除按钮
· 空状态：此规格暂未绑定基础产品
6.3 选择基础产品弹窗
· 搜索框：搜索基础产品名称/编号
· 列表项：圆形单选框 + 图片 + 名称 + 编号 + 单价 + 规格
· 选中效果：蓝色边框 + 浅蓝背景 + 勾选框变蓝白 ✓
6.4 售后退款弹窗
· Tab切换：📦 订单商品退款 | 🌽 基础商品退款
· 订单商品退款表格：商品名称/规格/已退款/购买/实付款/可退金额/本次退款数量/本次退款金额
· 基础商品退款表格：基础产品/规格/基础单价/已退款/购买总数/可退金额/本次退款数量/本次退款金额
· 底部提示：基础产品退款金额 = 退款数量 × 基础单价

8.2 绑定配置示例

剩余：7个玉米 + 3个鸡蛋（可继续退）
