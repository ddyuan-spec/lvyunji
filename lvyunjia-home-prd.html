二、项目背景与目标

2.1 业务背景

绿韵家App是公司自营大健康商城的C端载体，首页承担流量分发与商品曝光的核心职能。当前首页的分类导航为写死展示、无后台配置能力、跳转逻辑缺失；营销内容（超级品牌/爆款/特惠）与个性化推荐（猜你喜欢）能力薄弱。本次改版以设计稿为基准：明确分类导航 8 个入口的写死跳转逻辑；新增超级品牌/超级爆款/限时特惠三大营销专区，由后台"专题管理"统一配置，新增"专题类型"字段区分三个板块；板块标题/标签写死，卡片展示字段取专题内最新商品；并上线基于新算法的"猜你喜欢"推荐流，以提升首页流量分发效率与重点商品曝光。

2.2 项目目标

  • 业务目标：通过营销专区与个性化推荐缩短用户决策路径，提升商详转化率与加购转化率。
  • 用户目标：让用户打开App后能够快速通过分类导航到达目标内容、浏览营销活动、发现感兴趣的商品并完成加购。

4.1.2.2 详细逻辑规则

界面与展示规则

4.1.7.4 推荐算法策略（统一打分模型）

整体重构说明（评审结论）：本期取消"按用户状态分三策略"的旧模型，改为统一打分排序模型——每个候选商品先按"商品分层"获得基础分，再叠加当前用户对该商品的行为加分（加入购物车 / 下单 / 收藏 / 三天内浏览），按综合得分降序排列；商品排序值不再作为主排序键，仅用于同分二次排序。

综合得分公式

综合得分 = 基础分(按商品分层) + Σ 行为加分
行为加分（命中即加，可叠加；默认值 ⚠️ 待确认 @产品/算法）：
  + 加入购物车   : +30
  + 下单/已购    : +50
  + 收藏         : +25
  + 三天内浏览   : +15

排序规则（唯一排序链路）

  1. 主排序键：综合得分（基础分 + 行为加分）—— 得分越高越靠前。
  2. 同分二次排序：综合得分相同时，按商品排序值 desc（范围 0–999，值越大越靠前）。
  3. 同分三次排序：仍相同时，按修改时间 desc（最新修改在前）。

行为加分判定（per 用户 × per 商品）

  • 加入购物车：候选商品存在于当前用户购物车中 → 加购权重加分。
  • 下单/已购：候选商品在当前用户近 30 天内有下单记录（提交订单即算，含未支付） → 下单加分（已确认口径：提交订单即计入，不论是否支付/完结）。
  • 收藏：候选商品被当前用户收藏 → 收藏权重加分。
  • 三天内浏览：候选商品在当前用户近 3 天浏览记录中 → 三天浏览权重加分（即"三天内有浏览记录的商品也要加分"）。
  • 冷启动用户：无任何上述行为记录时，仅取基础分，按综合得分（=基础分）→ 商品排序 desc → 修改时间 desc 排序，与原冷启动曝光目标一致。

已确认 / 待确认：统一打分模型与"商品排序降级为同分排序"已与产品评审确认；各权重为默认值，⚠️ 待确认 @产品/算法 后可在后台推荐策略配置中调整（见 4.2.4）。原"近 7 天已购过滤"在统一打分模型下不再需要（已购本身已加分，无需单独过滤）。

六、验收标准

  • AC1：Given 客户端写死 8 个分类导航入口，When 用户浏览首页，Then 分类导航区按写死的名称/图标/顺序展示，点击入口按固定跳转目标页。
  • AC2：Given 后台仅配置部分分类入口（其余隐藏），When 用户浏览首页，Then 仅展示"是否展示=展示"的入口，且按排序权重排列。
  • AC3：Given 后台"专题管理"已配置专题类型=超级品牌/超级爆款/限时特惠的专题，When 用户浏览首页，Then 对应区域按设计稿样式展示专题卡片，点击卡片跳转专题详情页（商品列表页）。
  • AC4：Given 用户上滑首页，When 到达猜你喜欢区域底部，Then 触发分页加载，展示更多推荐商品。
  • AC5：Given 用户处于未登录态，When 浏览首页，Then 猜你喜欢走默认推荐策略，分类导航与营销专区正常展示。
  • AC6：Given 首页某模块接口失败，When 页面渲染完成，Then 仅失败模块展示错误占位，其他模块正常展示。
  • AC7：Given 后台"专题管理"未配置某专题类型（超级品牌/超级爆款/限时特惠）的专题，When 用户浏览首页，Then 该区域整体隐藏（已确认）。
  • AC8：Given 分类导航为写死展示，When 运营需调整首页分类入口，Then 须由研发修改客户端代码发版实现（无后台配置）。

七、关键边界设计检查清单

  • 网络与异常状态：弱网/断网时首页首屏展示骨架屏或全屏错误页；局部模块失败不影响整体；接口超时后提供重试。
  • 登录与游客态：分类导航/营销专区游客可见可点；猜你喜欢游客态走默认推荐；跳转目标页的登录拦截由目标页处理。
  • 极限值与空状态：商品名称超长截断；无数据模块隐藏或展示空态；分类导航全部隐藏时区域整体隐藏。
  • 版本兼容性：老版本升级后展示新首页；需确认是否保留服务端开关做灰度/降级。
  • 高并发与防重：分类导航点击、营销专区点击、猜你喜欢分页均做前端防抖/节流；后台配置保存做幂等与操作审计。
